# 3D 地球 · 点击足迹标记展开「照片环」（实现方案）

> 状态：**待实现**。本文件只描述方案，尚未改动任何代码。
> 范围：`/footprints` 3D 地球页（`travel-memory.js` / `travel-memory.css` / `footprint.html`）。
> 日期：2026-09-19
> 相关文档：`docs/province-city-cards-plan.md`（省份城市卡片与连线，另一条链路）

## 1. 目标

点击 3D 地球上的**足迹标记点**后，除了现有的足迹卡，还要在标记周围**直接铺开一环形照片**，
让"点一下就能看到多张图"，而不是先点开足迹卡、再点「打开图片墙」、再进城市视图才能看图。
点环上任意一张照片可**原地放大**查看（不是全屏），左右切换，逐级退回。

## 2. 已确认的决策

| # | 项目 | 结论 |
| --- | --- | --- |
| 1 | 与足迹卡的关系 | **不取代**足迹卡：卡片照旧从右侧滑入，照片环另外浮在标记旁 |
| 2 | 照片排列 | **围绕标记整圈 360° 径向排列**，不做成排/网格 |
| 3 | 展示数量 | **固定 5 张**（常量可调）。**环上不放「全部」入口** —— 看全部图片走右侧足迹卡上的「打开图片墙 · N」 |
| 4 | 放大看图 | **原地放大**：点缩略图 → 该角度变成大图（约 420×280）+ ←/→；**不全屏** |
| 5 | 窗口化范围 | **只有气泡这条链**窗口化；现有全屏灯箱（城市视图/城记里用的）保持不动 |
| 6 | 看全部图片的入口 | **不在环上**：由右侧足迹卡上的「打开图片墙 · N」进入城市视图的图片墙（复用 `openFootprintAlbum`） |
| 7 | 采样规则 | 图片多于 5 张时**均匀采样 5 张**（含第 1 张与最后一张） |
| 8 | 关闭语义 | **点空白 = 逐级退**（正在看放大图时先只收放大图，再点一次收环/卡片）；**Esc = 逐级退**（查看模式 → 环 → 卡片） |
| 9 | 再点同一标记 | **收起**（环 + 卡片一起收，toggle） |
| 10 | 图片说明（caption） | **不显示**（当前数据里该字段恒为空，见 §6.4） |
| 11 | 城市聚合标记 | **不做**照片环（保持现有城市卡） |
| 12 | 手机端 | **不做**（`COARSE_POINTER` 或视口 ≤ 820px 直接跳过），沿用现在的底部卡片 |
| 13 | 无图片的足迹 | 只出足迹卡，环不出现 |
| 14 | 卡片封面点击 | 默认**不做**（保持静态封面） |

## 3. 交互流程

```
点足迹标记（桌面端、有图片）
   ├─ 右侧足迹卡滑入（现状不变，0.45s）
   └─ 标记周围「照片环」淡入（0.2s，比卡片晚约 80ms）
        ├─ 点某张缩略图        → 原地放大成「查看模式」（其余缩略图淡出保留）
        │     ├─ ← / →         → 切换该足迹的照片（大图位置不动）
        │     └─ 点大图 / Esc  → 退回照片环（Esc 的第一级）
        ├─ Esc                 → 关掉照片环（卡片还在，Esc 第二级）
        ├─ 再点同一个标记       → 收起环 + 卡片
        └─ Esc（环已关）        → 关掉足迹卡（Esc 第三级）

点空白 → 逐级退：正在看放大图时**只收放大图**（环与卡片留着）→ 再点一次收环 +
卡片 / 省份卡片组（回到干净地球）
点另一个标记 → 直接切到那条足迹（旧环立即消失，不逐级）
看全部图片 → 右侧足迹卡上的「打开图片墙 · N」→ 城市视图的图片墙（环上不再放入口）
```

## 4. 照片环的几何与视觉

### 4.1 布局参数

| 项 | 值 | 说明 |
| --- | --- | --- |
| 展示数量 `PHOTO_RING_COUNT` | **5** | 环上不放其它入口（看全部走右侧卡片的「打开图片墙」） |
| 缩略图尺寸 | **按每张图片的实际宽高比等比缩放**，装进 `260 × 120` 的盒子（下限 `72 × 72`）；典型 4:3 照片 = **160 × 120**（约为初版 76×54 的两倍） | `background-size: contain`（极端比例被上下限夹过时不裁切） |
| 环形半径 | `max(下限, (2 × 最大半对角线 + 14) / (2·sin(步长/2)))` | 步长 = 360°/位置数；用**半对角线**而不是宽度，才能保证斜向相邻也不重叠 |
| 角间隔 | **72°**（5 张均分整圈） | 减量档为 3 张（120°）；半环档压进 180° |
| 起始角 | 由标记指向**远离视口中心**的方向 | `base = atan2(my - cy, mx - cx)`；第 i 张角度 = `base + i × 72°` |
| 环的整体包围盒 | 约 500~690 px 宽（随图片比例变化） | 图片放大到 2 倍后环必然变大；窄窗/贴卡片时按降级阶梯退到半环或减量 |
| 层级 | `position: fixed; z-index: 9997` | 与 `#markerTip`/卡片同级：在地球之上、顶部导航（10000）之下 |

> 同级 z-index 下由 DOM 顺序决定叠放：`#photoRing` 要插在 `#markerTip` 之后、`#markerCard`/`#cityCard` 之前，
> 这样卡片自然压在环上方，不需要靠更大的 z-index 去抢。环从半径 78px 起排布，**不覆盖标记中心**，
> 所以鼠标回到标记圆点上时，原有的悬停小气泡仍然可用。

### 4.2 引导线与选中态

- 静态**不画引导线**（6 条线会显得乱），靠"环抱标记"本身建立归属；
- 鼠标悬停 / 键盘聚焦某张缩略图时，临时画一条**细短线**（1px、暖白 0.5）连到标记，离开即消失；
- 选中态沿用现有的 `setMarkerSelected(index)`（足迹卡打开时已经调用过一次，环无需重复调用）：该标记放大、其余标记压暗 —— 与"点标记看卡片"的既有语言完全一致。

### 4.3 出现动画

- 每张缩略图从**标记中心径向飞出**到自己的角度位置：起点 `translate3d(markerX, markerY)` + `scale(.86)` + `opacity 0`，
  终点为其环上位置，`0.24s` `cubic-bezier(0.16, 1, 0.3, 1)`，逐张错峰 `40ms`；
- 与现有「卡片从标记飞出来」是同一套语言；`prefers-reduced-motion` 下直接落位、不做动画；
- 飞行期间把整体位置（transform）交给动画，不做环的重排（与省份卡片那套"入场锁"同理）。

### 4.4 避让与降级阶梯

按顺序逐级降级，尽量保住"整圈 360°"：

1. **整体平移**：环的包围盒超出视口时，先把整圈平移进视口（相对角度不变）；
2. **避开右侧足迹卡**：把 `#markerCard` 的矩形当障碍物 —— 先试多个朝向，再**沿最小位移轴把整圈推开**
   （上限 400px，卡片宽约 410px；**宁可环略微偏离标记，也不能让照片压在卡片后面**），推完再钳回视口；
3. **退化成半环**：标记贴边、整圈怎么放都会压住卡片或出界时，只取朝向视口内的半圈（角度间隔 45°）；
4. **缩小**：缩略图 76 → 64，半径 78 → 66；
5. **减量**：展示 5 → 3 张（其余不进环，看全部图片仍走右侧卡片）。

## 5. 查看模式（原地放大）

| 项 | 规格 |
| --- | --- |
| 触发 | 点环上任意一张缩略图 |
| 形态 | **环上另有一个独立的大图元素**（不是复用被点的那张缩略图）：从被点缩略图的原位展开到**原角度**的大图 —— 按实际宽高比装进 `480 × 340` 的盒子（圆角 12px）；为不压住标记，半径外移到 130px |
| 其余缩略图 | 淡出（`opacity 0`）但保留位置，退回环时无需重排；**缩略图永远只显示自己那张** |
| 信息行 | 计数胶囊「第 3 张 · 共 12 张」（**不显示**图片说明文字，见 §2 第 10 条） |
| 位置指示 | 大图下方一条点带：全量 N 个点，**环上那 5 张亮一档**、当前这张点亮（琥珀）；N > 40 时只留计数 |
| 一行说明 | 「环上展示 5 张 · 全部 12 张在「图片墙」」——环上已是全量（≤5 张）时不显示 |
| 切换 | ← / → 切换该足迹的**全部**照片（不只环上 5 张）；切换时大图位置不动，大图尺寸按新图比例重算 |
| 退回 | 点大图本身 / Esc → 回到照片环 |
| 进入全部 | 右侧足迹卡上的「打开图片墙 · N」→ `openFootprintAlbum(fp, trigger)`（城市视图图片墙） |
| 关闭按钮 | 右上角 ×：挂在图片**右上角圆角的外侧**、沿 45° 对角线摆放（`PHOTO_RING_CLOSE_OFFSET = 18`，内角刚好贴着圆角），并钳进视口避免贴边时被切；只斜向摆放、不旋转按钮本身（旋转 45° 会把「×」转成「+」） |
| 层级 | 查看模式下整个环抬到 `z-index: 9998`（`#photoRing.is-viewing`），**压在右侧足迹卡（9997）之上** —— 否则大图铺到右半屏会被卡片切掉一块。缩略图这时都是 `is-dim`（opacity 0），跟着整层抬起不会有别的观感变化；根节点仍是 `pointer-events: none`，卡片没被大图盖住的部分照样能点 |

## 6. 图片数据与加载

### 6.1 数据来源

`cityWallImages(fp)` → `[{ url, caption }]`（优先 `galleryImages`，没有就退回 `fp.image`）。

### 6.2 均匀采样（> 5 张时）

```
n <= 5  →  全部展示（环上没有任何"更多"入口，看全部在右侧卡片里）
n >  5  →  idx_i = round(i × (n - 1) / (K - 1))，i = 0..4，K = 5
           例：n = 12 → 0, 3, 6, 8, 11（含第一张与最后一张）
           去重：若取整后重复，用 Set 补齐到 5 个（保证首张一定是封面）
```

### 6.3 加载

- 全部走**共享封面队列** `loadCardCoverImage(url, done, options)`（并发 3、成功缓存、失败静默重试一次）；
- 入队顺序＝采样顺序（第 1 张最先），避免一次打 6 个请求；
- 查看模式里的**大图与缩略图是同一个 URL** → 命中缓存，不会重复下载；
- 缩略图：底色骨架 → 加载成功淡入（0.25s）；加载失败保留骨架（可点重试一次）；
- 切换查看模式时**预加载左右各一张**（与灯箱 `preloadLightboxNeighbors` 同样的做法），切换无白屏。

### 6.4 为什么不做图片说明文字

当前数据链路里 `caption` 恒为空：`Footprint.GalleryImage` 只有 `url` / `order`；
前端 `mapTestJsonEntry` 把它写死成 `caption: ''`。要做真说明文字需要：
编辑界面加输入框 → 模型加字段 → 前端透传（独立功能，不在本次范围）。

## 7. 状态、互斥与收口

### 7.1 状态

```
photoRing = {
  active: false,        // 环是否打开
  viewing: false,       // 是否处于查看模式
  fp: null,             // 当前足迹
  index: 0,             // 查看模式下第几张（相对全部图片）
  entity: null,         // 跟随的标记实体
  items: [],            // 环上的缩略图元素
  token: 0              // 世代号：动画/异步回调作废用（同省份卡片那套）
}
```

### 7.2 互斥

| 打开 / 触发的动作 | 对照片环的处理 |
| --- | --- |
| 打开省份卡片组 | 先关环 |
| 打开城市卡（点城市聚合标记） | 先关环 |
| 打开城记 / 票根册 / 图片墙 | 先关环 |
| 打开另一条足迹的卡（点别的标记） | 先关环，再按新标记重建 |
| 进入查看模式 | 不关环（环保留在背后） |

### 7.3 收口清单（这些既有路径都要挂上关闭）

| 位置 | 说明 |
| --- | --- |
| `LEFT_CLICK` 的"点空白"分支 | 逐级：在查看模式时**只收放大图**（环与卡片留着）→ 再点一次收环 + 卡片 + 省份卡片组 |
| 主 `keydown` 的 Esc 链（`addEventListener` 在 1433 行，省份分支在 1486 行） | 逐级：查看模式 → 环 → 卡片 |
| `closeGlobeOverlays()`（切 2D） | 关环 |
| `updateIntroVisibility()`（回到整球视图） | 关环 |
| `applyMarkerMode()`（聚合/展开切换） | 关环（展开态/聚合态变化时环的锚点会失效） |
| `footprints:loaded`（数据重载） | 关环 |
| `openCityWall()` / `setTicketView(true)` | 关环 |
| `activateCityCards()`（省份卡片组） | 关环 |

### 7.4 跟随与背面

- 挂 `viewer.scene.postRender`，与 `updateMarkerTipPosition()` 同一套：`markerScreenPosition(index)` 取屏幕坐标，
  复用现有"相机没动就跳过"的判定，静止时不产生每帧开销；
- 标记转到地球背面 → 环**整体淡出但保留状态**，转回正面再淡入（不销毁，避免转一半被关掉）；
- 打开环时 `pauseAutoRotate('photo-ring')`，关闭时 `resumeAutoRotate('photo-ring')`。

## 8. 键盘与无障碍

- `markerFocusLayer` 的屏幕外按钮：**Enter** → 打开足迹卡 **和**照片环，焦点落在第一张缩略图；
- 环内元素全部是 `button`：缩略图（`aria-label="第 3 张图片，共 8 张"`）、查看模式的箭头与关闭；
- 查看模式：`←` / `→` 只在查看模式容器内响应（不抢占地球的键盘操作）；`Esc` 逐级；
- 容器 `role="group"` + `aria-label="稻城亚丁 · 8 张图片"`（非模态，不夺焦点）；
- 关闭时焦点归还触发它的标记按钮（复用 `lastKeyboardMarkerBtn` 的既有写法）。

## 9. 边界情况

| 场景 | 处理 |
| --- | --- |
| 足迹没有图片 | 不出环，只出足迹卡 |
| 只有 1~5 张图 | 环上全部展示（环上本来就没有"更多"入口） |
| 标记在地球背面 | 环淡出保留，转回正面复现 |
| 标记靠近屏幕边缘 | 按 §4.4 降级（平移 → 避卡片 → 半环 → 缩小 → 减量） |
| 同城多个标记很近 | 复用 `setMarkerSelected` 的压暗；必要时环整体半透明 0.96 |
| 手机 / 触屏 | 不做环，沿用底部卡片 |
| 标记密集时连续点不同标记 | 旧环立即消失、新环重建（不逐级、不叠加） |
| 打开环后拖地球 | 环跟随标记移动（这是本方案的核心观感） |
| 拖动地球后松手落在标记上 | **是否误触发点标记沿用现状**（本次不加新阈值）。注意：代码里那个 5px 判定（约 1042 行）只用于"拖动后取消自动旋转"，**不是**点击抑制。实现时先实测一次；若确实会误触发，再补一个"按下/松开位移 > 5px 就忽略这次点标记"的判定 |

### 第四轮调整（同日）：把"半环绕行"还给布局

能半环绕行就半环绕行；只有当半环也压住卡片时，才用更长的推距去换"照片不被挡住"。

### 第五轮调整（同日）：卡片矩形取错 + 半环朝向写死

第四轮部署后又出现两个现象（用户反馈）：

1. 拖动地球让足迹点**绕到卡片后面**时，照片固定成"上半圆"，右侧照片仍被卡片压住；
2. 足迹点移到**卡片上方**时又铺成完整的整圈，圆的下半被卡片压住。

根因有两个，第一个是纯 bug：

| # | 问题 | 说明 |
| --- | --- | --- |
| 1 | **障碍物矩形取错** | `#markerCard` 的静止态是 `top: 50%` + `transform: translateY(-50%)`，而 `photoRingCardRect()` 走的 `cardLayoutRect()` **刻意只按定位属性推算、不读 transform**（那是为入场动画服务的）。算出来的盒子因此比真实卡片**低了半张卡高（约 235px）**：标记在卡片上方时以为"没压住"而铺整圈，标记转到卡片后面时又按"往上抬"去躲，于是固定成上半圆 |
| 2 | **半环朝向写死** | 候选朝向只有 `远离视口中心 / 背向卡片` 两组各 ±90°（7 个固定角度），弧线只能在"上下半圆、左右半圆"之间跳，标记绕卡片移动时不会跟着转 |
| 3 | **按包围盒判重叠** | 半环是"弧"，包围盒的四角本来是空的；按包围盒算重叠会把"照片其实没碰到卡片"也算成压住，逼着整环离开标记 |

修法：

- `photoRingCardRect()` 改用 `getBoundingClientRect()` 读卡片**真实**屏幕矩形（入场动画落定后再重排一次，
  避开动画期间缩放带来的几像素误差）；`cardLayoutRect()` 保持原样，不影响入场方向那套逻辑。
- 半环朝向改为**沿整圈连续扫描**（`PHOTO_RING_ARC_STEP_DEG = 5°`，72 个朝向），
  弧线自己去找空位；整圈因为近似旋转对称，仍只取几组有语义的朝向。
- 重叠改成**逐张照片**算（`photoRingOverlapArea`），推开量也按"真的被压住的那几张"算
  （`photoRingPushVector`，四方向取最小位移）；推完再钳回视口，推距仍然计价。
- 加入**朝向连续性偏好**（`photoRingArcAngle`，权重 0.4 × 夹角）：多个朝向同样干净时
  （比如一圈都空着）弧线贴着上一帧的朝向，不会左右翻边；首次开环以"背向卡片"为基准。

离线仿真（1920×1080，卡片真实矩形 1498~1834 × 305~775，4:3 照片）：

| --- | --- | --- | --- |
| 卡片正上方 (1770,180) | 半环 / 5 张 | 255° | 0 / 0 |
| 卡片后面（中间）(1666,540) | 半环 / 5 张 | 140° | 0 / 0 |
| 卡片正左 (1330,540) | 半环 / 5 张 | 180° | 0 / 0 |
| 卡片左上 (1300,300) | 整圈 / 5 张 | — | 0 / 0 |
| 远处中间 (900,500) | 整圈 / 5 张 | — | 0 / 0 |

沿卡片左侧自下往上移动时弧线朝向连续变化（220°→210°→195°→175°→160°→145°→135°），不再固定成上下半圆。

### 第六轮调整（同日）：屏幕边缘也当成障碍物 + 锚点出屏淡出

反馈：避让只对右侧卡片生效；把足迹点从上/下/左拖出屏幕后，照片还是一整圈挂在屏幕边上。

根因：卡片是**障碍物**（要绕开、要付推距代价），而视口边界走的是另一条路 —— **免费的整体平移**
（把包围盒塞回视口，不计价）。所以贴边时布局只会把整圈平移过去、形状不变；
而平移量一旦超过环半径，标记就跑到照片圈外面去了，看起来就是"一圈无主的照片"：

| 标记位置 | 旧行为 | 平移量 |
| --- | --- | --- |
| 贴左/上/下内侧 60px | 整圈 | 194~214px（环半径 182px） |
| 左外 40 / 120 / 300px | 整圈 | 314 / 394 / 574px |

修法（两条一起上）：

- **B：把"塞进视口的整体平移"也计价**（`PHOTO_RING_EDGE_PUSH_COST = 0.04`/px），屏幕边缘因此和卡片一样是
  真的障碍物；贴边时布局会退成**朝屏幕内侧的半环**，而不是把整圈推走。平移量按
  `PHOTO_RING_EDGE_SHIFT_LIMIT = 150` **封顶**计价 —— 不封顶时布局会为了省推距去选更小的档
  （实测：不封顶时紧凑档占到 38% 的位置，照片会无故缩小）。
- **A：锚点滑出视口就整环淡出**（`PHOTO_RING_EDGE_FADE_PX = 70`），沿用"标记转到地球背面就淡出"同一套语言：
  `updatePhotoRingPosition()` 把出屏深度换算成 `--photo-ring-fade`（0~1）写在根节点上，
  `#photoRing.show { opacity: var(--photo-ring-fade, 1) }` 负责渲染；淡到一半以下时关掉点击
  （`.is-edge-faded`）。状态与布局全部保留，拖回来反向淡入，不用重新点标记。

离线仿真（1920×1080，4:3 照片）：

| 位置 | 旧行为 | 新行为 |
| --- | --- | --- |
| 贴左/上/下/右内侧 60px | 整圈，平移 179~214px | **半环，不平移** |
| 贴左内侧 130px | 整圈，平移 144px | 半环（或紧凑整圈，平移 <100px） |
| 屏幕中部 | 整圈，平移 0 | 不变 |
| 卡片附近 | 半环绕行 | 不变（边缘计价只在贴边时生效） |

全网格（视口内 40px 步长，有卡片 / 无卡片两种）：压卡片 0、出界 0。
副作用记录：贴边带内仍可能出现紧凑档（照片小 18%）、角落可能出现 3 张档 —— 这是既有的"空间不够"降级阶梯，
不再影响中部与卡片附近的观感。

### 第七轮调整（同日）：大图改用独立元素

反馈：放大后按 ← / → 翻过图，再关掉放大，**原来的缩略图变成了翻到的那张**。

原因：查看模式当时**复用了被点的那张缩略图元素**（`photoRingViewerEl` 就是 `els.items[slot]`），
`renderPhotoRingViewImage()` 把翻到的图片 URL 直接写进这个缩略图；顺带还会把该槽位的
`dataset.natW/natH`（缩略图尺寸唯一的依据）覆盖成别的图，于是那个槽位的缩略图连尺寸都跟着错。

修法：环里新增一个**独立的大图元素**（`els.viewer`，`photo-ring-item is-viewer` + 平时 `is-slot-hidden`），
它不参与环的布局：

- 进入查看模式：把它先钉在被点缩略图的原位（关掉过渡），下一帧再交给 `applyPhotoRingTransforms`
  移到查看位置 —— 保留"从缩略图飞出来"的观感；
- 圈上所有缩略图统一 `is-dim`（不再有"某一张被排除在淡出之外"的特例）；
- 退出：大图重新 `is-slot-hidden` 并清掉内联尺寸，缩略图恢复显示；
- 焦点跟着大图走：进入时若焦点在环里就交给大图，退出时回到当前这张对应的槽位 ——
  否则焦点会停在 `opacity 0` 的缩略图上（和之前标记按钮那次同类的问题）。

### 第八轮调整（同日）：单张图片的足迹

反馈：足迹只有一张图片时，照片直接盖在足迹点上。

两个原因：

| # | 问题 | 说明 |
| --- | --- | --- |
| 1 | **单张根本不参与布局** | 候选循环里写着 `if (visible.length < 2) return;` —— 只有一个位置时所有档位都被跳过，`layoutPhotoRing` 直接返回、`photoRingLayout` 保持 null，于是那张缩略图停在**入场动画的终点（正好是标记位置）**，`applyPhotoRingTransforms` 也因为没布局而整个早退 |
| 2 | **大图的外移距离是按旧尺寸定的** | `PHOTO_RING_VIEW_RADIUS = 130` 是缩略图时代（76×54，半高 27）定的；现在大图最大 `480×340`（半对角线可达 283），130px 的偏移必然把标记压在底下 |

修法：

- 候选循环放开到 1 张（`if (!count) return;`）；半径公式在 `count < 2` 时退化 ——
  没有"相邻"要避，只要求这张自己不压住标记：`radius = max(base, 半对角线 + 14)`
  （原公式在 count=1 时 `sin(π/1/2) = 0`，半径会直接爆成天文数字）。
- 大图的外移距离改为**按大图自己的半对角线**推：`max(130, hypot(半宽, 半高) + 24)`；
  钳进视口之后如果又盖回标记上，再沿"移动最少"的那条轴把它推到标记之外（推不进就保持钳制位置，
  不把大图挤出屏幕）。

离线仿真（1920×1080）：

| 图片比例 | 单张缩略图 | 离标记 | 压标记 |
| --- | --- | --- | --- |
