## 使用约定

- 示例中的地点、日期、票号和个人信息应使用虚构或已获授权的内容。

- 更新提示词时，优先新增版本或在下文记录改动，不要静默覆盖旧版本。
- 仓库不附带生成模型、API Key 或运行脚本；使用者需自行准备兼容的图片生成工具。
